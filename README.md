# csci5499A_Project1
Project 1 - Bryson

part_1.ipynb: Part 1 (ViT patches, predictions, confusion matrix)
part_2.ipynb: Part 2 (CLIP similarity, prompt templates, image-image similarity)

How to run:
1. Open the notebook in Google Colab (CPU is fine).
2. Run all cells (Runtime > Run all).
3. When asked, upload images.zip. It should contain images/glasses, images/mouse,
   images/mug, images/watch, and images/waterbottle, with 4 photos in each.

Pretrained weights download automatically. Part 2 installs CLIP in its first cell.
